01 / The premise

We didn't copy the sound. We rebuilt the machine.

REDRAW began with measurements, not binaries. File inventories. Export tables. String buckets. The observable behavior of a format. From those facts, a new DAW was drawn: original engines, original names, original signal paths, and a clean-room paper trail.

The result is not a clone. It is a working instrument with its own voice, its own architecture, and its own set of deliberate limits. Every DSP path follows published technique; every shipped name belongs to REDRAW.

01 / Measured

Facts, not decompilation.

Formats and capabilities were mapped from observable behavior, file inventory, and public technique. No engine code was decompiled.

02 / Rebuilt

Original DSP, published method.

PolyBLEP oscillators, RBJ biquads, TPT filters, FDN reverberation, look-ahead limiting, STFT analysis, granular overlap-add.

03 / Original

Names and visuals of its own.

49 instrument names, 74 effect names, four themes, and a vector visual language created for REDRAW. Nothing traced.

04 / The engine

The continuous path allocates nothing. Locks nothing. No excuses.

A lock-free command ring carries edits from the UI. Structural changes are built off-thread and swapped at block boundaries. The callback renders 512 frames at a time, then hands the displaced graph back through a garbage ring for the control thread to drop.
